# 논리 미궁: 대우의 열쇠

원래 명제(p → q)의 올바른 대우(~q → ~p)를 골라 다섯 개의 방을 탈출하는 논리 퀴즈 게임입니다.

- 문제는 매번 무작위로 나옵니다. 직접 쓴 문제 29개에 숫자를 바꿔 만드는 문제 3종이 섞입니다.
- 뒤로 갈수록 ‘그리고’, ‘또는’이 섞인 복합 명제가 나오고, 답을 고르면 보기가 역·이·대우·잘못된 부정 중 무엇인지 해설해 줍니다.
- 금화를 모아 상점에서 여분의 열쇠, 통찰의 렌즈, 테마를 살 수 있습니다.
