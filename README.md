# 논리 미궁: 대우의 열쇠

원래 명제(p → q)의 올바른 대우(~q → ~p)를 골라 다섯 개의 방을 탈출하는 명제 논리 퀴즈 게임입니다.

- 모든 방은 「집합과 명제」의 명제 문제이고, 명제에 담긴 수학은 고등학교 1학년 공통수학1 · 공통수학2(다항식, 방정식과 부등식, 경우의 수, 행렬, 도형의 방정식, 집합과 명제, 함수와 그래프)에 나오는 내용만 씁니다. 방마다 그 단원을 보여 줍니다.
- 대우를 찾는 방을 중심으로 역 찾기, 부정, 필요·충분조건, 반례, 참·거짓, 진리집합 방이 섞여 나오고, 마지막 방은 ‘그리고’·‘또는’이 섞인 명제입니다. 답을 고르면 보기마다 해설을 보여 줍니다.
- 유형별 연습(열쇠 · 금화 없이 한 유형만), 오답 노트(틀린 문제와 해설 모음)가 있습니다.
- 금화를 모아 상점에서 여분의 열쇠, 통찰의 렌즈, 보호의 인장, 불사조 깃털, 지혜의 촛대와 테마 5종을 살 수 있습니다.
- Google 계정으로 로그인하면 금화와 기록이 계정에 저장되고, 친구 코드나 초대 링크로 친구를 맺어 탈출 기록 순위를 보고 금화를 보낼 수 있습니다. 홈 화면에 앱으로 설치할 수도 있습니다.
