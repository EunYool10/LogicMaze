# 논리 미궁: 대우의 열쇠

원래 명제(p → q)의 올바른 대우(~q → ~p)를 골라 다섯 개의 방을 탈출하는 논리 퀴즈 게임입니다.

- 문제는 매번 무작위로 나옵니다. 직접 쓴 문제 72개에 숫자를 바꿔 만드는 문제 8종이 섞입니다.
- 대우를 찾는 방을 중심으로 역·이 찾기, 부정, 필요·충분조건, 반례 방이 섞여 나오고, 마지막 방은 ‘그리고’·‘또는’이 섞인 명제입니다. 답을 고르면 보기마다 해설을 보여 줍니다.
- 금화를 모아 상점에서 여분의 열쇠, 통찰의 렌즈, 보호의 인장, 불사조 깃털, 지혜의 촛대와 테마 5종을 살 수 있습니다.
